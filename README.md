# Natural Language Processing Assignments

Implementations and experiments from a graduate Natural Language Processing
course.

## Assignments

- [BM25 Similar Words](assignments/bm25-similar-words/README.md): compares
  context-vector weighting and similarity configurations for the word
  `time`.

## Data Policy

Course datasets are not included in this repository. Each assignment explains
where an authorized local copy must be placed.

Generated full-corpus text and full-vocabulary result tables are also excluded.
The notebooks generate them locally when executed.

## Privacy

The repository excludes personal information, local filesystem paths,
credentials, team-member information, and private academic records.
